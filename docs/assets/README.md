# Project assets

This directory contains the two reference assets supplied with the Contract Risk Analyzer project.

| Asset | Description |
| --- | --- |
| [`enterprise-contract-risk-scoring-policy.pdf`](enterprise-contract-risk-scoring-policy.pdf) | Authoritative enterprise scoring framework covering category definitions, judge consensus, confidence, risk bands, action logic, and audit requirements |
| [`contract-risk-analyzer-demo.mp4`](contract-risk-analyzer-demo.mp4) | Product walkthrough video supplied with the source archive |

The PDF is the source of truth for policy formulas. The implementation-oriented overview in [`../scoring-policy-summary.md`](../scoring-policy-summary.md) is provided for navigation and should not replace the supplied policy document.
